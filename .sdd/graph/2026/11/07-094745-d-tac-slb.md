The two programs are named `sdd-grounding-gate` and `sdd-capture`, their skills `sdd-helpers:grounding` and `sdd-helpers:capture`, and the development switch `SDD_HELPERS_BIN_DIR`; the plugin option keys and the `GROUNDING GATE:` prefix of every gate refusal keep their agentic-helpers form.

The names match the repository they ship from (20261107-093312-d-cpt-3aq), and they let an older agentic-helpers install sit beside sdd-helpers without two plugins putting the same command name on the `PATH`. The option keys `grounding_gate_enabled`, `capture_enabled` and `capture_remove_draft` and the refusal prefix stay as they were, so existing settings carry over unchanged and skills and agents quoting a refusal keep matching it. The code base these names replace is recorded in 20261107-094237-d-tac-imc.

Rejected: keeping `agentic-grounding-gate`, `agentic-capture` and the `agentic-helpers:agent-*` skill names. The `agentic` prefix no longer matches the repository, and during the overlap with agentic-helpers both plugins would put the same command on the `PATH`.

Accepted costs: every string, document, skill and test naming the programs changed with them. `sdd-capture` reads like a subcommand of sdd itself and would clash if stock sdd ever adds one by that name.

Settled: the renamed programs ship in commit `c77da49`, so nothing follows from this decision.
