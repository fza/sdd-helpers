sdd-helpers v1.1.2 is released: tag `v1.1.2` and release commit `fe4cc9c`, with an immutable GitHub release carrying archives for darwin and linux on amd64 and arm64 and their `checksums.txt`. The `release` workflow ran from `main` at `f3e0bcf` as run 42585665019, following v1.1.1 (20261107-191258-s-tac-9gh).

It ships two changes to the plugin's skills:

- Commit `f3e0bcf` cuts `sdd-helpers:capture` and `sdd-helpers:grounding` to what bears on every load, from about 14.1k and 12.7k characters to 4.0k and 4.7k. The rest moves to reference files the skills link: `references/sdd-capture.md` under capture, `references/config.md` and `references/refusals.md` under grounding. A `SKILL.md` loads whole each time it is needed, so its size is paid on every load; the cut serves the pull to keep what an agent reads no costlier than it needs to be (20261107-092827-d-stg-qsj). The same commit lowers the skills' character budgets in `source/hooks/internal/plugin/skillbudget_test.go` to 4300 and 4900 to match.
- Commit `af4ebd8` adds a test holding every plugin skill to the Agent Skills specification, so any agent reading that format loads them, not only Claude Code.

Its release fixture, `source/hooks/test/fixtures/releases/v1.1.2/`, is committed in `82721c1`: the fixture script drove v1.1.2's `sdd-grounding-gate` through a scripted session and recorded the state it left and every answer it gave, which later builds replay.
