sdd-helpers v1.1.0 is released: tag `v1.1.0` and release commit `9c5d7cc`, with an immutable GitHub release carrying archives for darwin and linux on amd64 and arm64 and their `checksums.txt`. The `release` workflow ran from `main` at `59a5c2d` as run 42368885314.

It brings the daily release folder pruning (20261107-123448-s-tac-vpf) to every machine that installs the plugin.

Its release fixture, `source/hooks/test/fixtures/releases/v1.1.0/`, is committed in `cffa1b2`: the fixture script downloaded the darwin arm64 archive, matched it against the release's `checksums.txt`, drove v1.1.0's `sdd-grounding-gate` through a scripted session, and recorded the state it left and every answer it gave. A test replays that session against each later build, so a release that would lose the reads, grounded drafts or shown sets a v1.1.0 session kept fails before it can be cut.
