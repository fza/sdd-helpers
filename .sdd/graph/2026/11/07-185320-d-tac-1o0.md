`sdd-grounding-gate collapse` hands Claude Code a shortened sdd answer as a plain JSON string under `hookSpecificOutput.updatedToolOutput`, the same form the agent receives an untouched sdd answer in, and encodes it with `SetEscapeHTML(false)`, so `<`, `>` and `&` stay as they are. It ships as a patch release, v1.1.1.

**Why.** The collapse sends its answer under `updatedMCPToolOutput` as an MCP content wrapper, `{"content":[{"type":"text","text":"<json>"}]}`, a form the starting point at agentic-helpers v2.28.0 (20261107-094237-d-tac-imc) carried over unchanged. Claude Code hands an sdd MCP answer to the agent as a plain string, so it serializes the wrapper object, and the agent reads the whole shortened answer as one escaped string: every quote and line break gains a backslash, and Go's default encoder adds `<` for `<`. Claude Code 2.1.316 to 2.1.319 delivered every collapsed answer that way. agentic-helpers' live proof of the collapse (`github.com/fza/agentic-helpers:20261101-230347-s-tac-fzn`) took the escaping as a small cost. It is small only where much collapses: a repeated `show` whose chain shortens went from 4468 characters to 3512, but an `mcp__sdd__show` whose asked entry carries a long body, and whose chain has little to shorten, comes back longer than the untouched answer. The collapse then costs the tokens it exists to save, against the pull to keep output the agent was already shown short (20261107-092827-d-stg-qsj). Claude Code's hook docs say a replacement must match the tool's output shape, and name `updatedToolOutput` as the key for every tool, `updatedMCPToolOutput` as the older one for MCP tools only.

**Rejected.** Keeping the wrapper and replacing an answer only when the wrapped text comes out shorter: an answer with little to shorten stops costing extra, but the escaping stays on every answer that does collapse. Leaving the form as agentic-helpers had it: answers where little collapses keep costing more than the original. Answering in whatever shape the hook received, a string as a string and a content array as an array: code and tests for shapes no current Claude Code sends.

**Accepted costs.** The hook's output contract changes, and `docs/grounding-gate/architecture.md`, which names `updatedMCPToolOutput`, changes with it. The plain-string form is proven only by a live run after the build. Should Claude Code change the shape it hands an MCP answer in again, the replacement mismatches again until a release follows.

**Acceptance.**
- A repeated `mcp__sdd__show` in a live Claude Code session reaches the agent as the shortened JSON object, with no `content` wrapper and no escaped quotes.
- The PostToolUse output `sdd-grounding-gate collapse` prints carries the answer as a string under `hookSpecificOutput.updatedToolOutput` and no `updatedMCPToolOutput` key; a test fails on either regression.
- An answer holding `<`, `>` or `&` keeps them unescaped in the shortened answer; a test fails on `<`.
- `docs/grounding-gate/architecture.md` names `updatedToolOutput` and the plain-string form.
- The fix is released as v1.1.1.
