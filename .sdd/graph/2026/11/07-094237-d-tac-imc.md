sdd-helpers' code starts from agentic-helpers commit `ecb474a`, release v2.28.0, with every later change to the grounding gate and the capture command ported onto it by hand from a private codebase that carried them further. That codebase is deliberately not named anywhere in this repository.

The repository (20261107-093312-d-cpt-3aq) needed the two programs as standalone binaries, each wired through the plugin's `hooks.json`, which is the shape described in 20261107-093513-s-cpt-qxc. agentic-helpers v2.28.0 already ships them in that shape, so starting there kept the structure and changed only names and scope. The later changes come on top so that sdd-helpers starts from the newest behaviour of both programs, not from an older one.

Rejected: starting from the other codebase's copy, which already held the later changes. There both programs run through one binary's dispatch code under that product's names, so both would first have had to be rebuilt into standalone binaries.

Accepted cost: that codebase's changes to both programs since v2.28.0 had to be checked line by line and ported by hand, among them the refusal of relative attachment paths in a capture, fixes to the shell-command walk, and tests for safe file replacement.

Settled: the port is complete in commit `c77da49`, so nothing follows from this decision.
