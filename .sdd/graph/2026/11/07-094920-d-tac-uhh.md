The grounding gate in sdd-helpers has no seat exemption: the `.sdd/grounding.yaml` key `exempt_seats`, at the top level and under `show_depth`, is gone with no replacement, and `enabled: false` is the only way a project opts out of the gate.

In agentic-helpers the key let a named seat pass every check (github.com/fza/agentic-helpers:20261002-142251-d-tac-jjo). The gate learned a session's seat by reading another plugin's private memory store files. sdd-helpers keeps to sdd workarounds and has no store of its own (20261107-093312-d-cpt-3aq), and that store's file layout has already changed once, so the read would break silently the next time it changes. sdd-helpers reads no other plugin's memory store.

Rejected:

- An environment variable set when Claude Code starts, exempting the whole session. The exemption would be decided at launch rather than when a seat is claimed, and every launcher would need changing.
- Keeping the store read. sdd-helpers would carry a copy of that store's layout code, and any change to the layout would end the exemption without a word.

Accepted costs: sdd-autopilot's main session, the only user of the key (`exempt_seats: ['main']`), is gated like any other session. `enabled: false` covers the whole project, never a single session. A lingering `exempt_seats` key is ignored rather than refused, since the file is read loosely.

Settled: the key is gone in commit `c77da49`, so nothing follows from this decision.
