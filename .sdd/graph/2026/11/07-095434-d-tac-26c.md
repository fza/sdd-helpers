agentic-helpers ships the release that removes its grounding gate and `agentic-capture` only after sdd-helpers v1.0.0 exists, and from then on names sdd-helpers at session start in every graph project that does not have it installed.

The removal is committed in agentic-helpers as `dccf21e`, not yet released. Its patch release waits for sdd-helpers v1.0.0 (20261107-095305-d-tac-d0f), so no user is left between a gate that is gone and a replacement that cannot be installed yet; the distinct names (20261107-094745-d-tac-slb) let both plugins sit side by side until then. After the removal, `agentic-helpers check` prints, at session start, in a project carrying `.sdd/` and only while no `sdd-helpers@*` key is in `~/.claude/plugins/installed_plugins.json`:

    the grounding gate and agentic-capture moved to the sdd-helpers plugin: claude plugin marketplace add fza/sdd-helpers, then claude plugin install sdd-helpers@sdd-helpers

A README section in agentic-helpers says the same.

Rejected:

- The README section alone. agentic-helpers updates silently, so most users never read it and would simply find the gate gone.
- A line in every graph project. It would remind users who already installed sdd-helpers in every session, with no way to switch it off.

Accepted costs: new check code and tests in agentic-helpers, which otherwise takes fixes only, and that check reads Claude Code's `installed_plugins.json`, a file rather than a stable interface, so a change to it in Claude Code can silence or misfire the line.

Pending: fulfilled once agentic-helpers has released the removal after sdd-helpers v1.0.0.
